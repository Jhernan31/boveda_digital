# boveda_digital
Para el proyecto de Boveda Digital, opte por crear una especie de agenda para almacenar contraseñas de sitios web, lugares, cuentas.
Si bien esta es informacion critica para cualquier persona, para este proyecto solo se penso de forma de poder practicar lo aprendido
durantes este curso de POO, ya que no se han aplicado formas de seguridad o encriptacion de los datos en el archivo csv.

Este programa consta de un menu de mantenimiento desde el cual se pueden agregar registros nuevos, listar los ya existentes en el archivo
csv. Se pretendia completar las demas funciones como buscar especificamente por criterios y poder editar/borrar registros. Lastimosamente
por razones de tiempo no he logrado terminar estas funciones antes de la fecha final de entrega.

En cuanto a los recursos externos utilizados, me base en pedirle a la IA Gemini que actuara como mi instructor de programacion y me ayudara 
en el proceso de creacion, importante mencionar que le pedi que no me diera el codigo sino que me fuera indicando los pasos por los que debia 
iniciar, transitar y finalizar el proyecto. En algunos puntos le pedi me diera ejemplos de codigo que me sirvieran para entender lo que me 
pedia hacer.
